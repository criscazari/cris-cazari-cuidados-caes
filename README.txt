# Cris Cazari — Cuidados com cães

Protótipo de homepage responsiva para portfólio de passeios, hospedagem e cuidados na casa do tutor.

## Estrutura

- `index.html` — estrutura da página
- `style.css` — identidade visual e responsividade
- `script.js` — menu mobile, animações, navegação e galeria
- `images/` — fotos e favicon

## Antes de publicar

No `index.html`, procure por:

`5518999999999`

e substitua pelo número real do WhatsApp com DDI + DDD, sem espaços ou símbolos.

Também ajuste:

`@criscazari`

para o Instagram correto.

## Testar localmente

Basta abrir `index.html` no navegador.

Para um teste mais fiel, pode usar o Live Server do VS Code.

## Fotos

A foto enviada pela Cris já está em `images/cris-com-cao.jpg`.
As outras imagens da galeria são recortes da mesma foto apenas para o protótipo. Quando houver novas fotos, coloque-as na pasta `images` e altere os caminhos no HTML.
